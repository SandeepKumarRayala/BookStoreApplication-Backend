## 📌 Project Overview

This application was collaboratively developed by a team of **six members**, with each member contributing to different services and features. The application consists of multiple services, including **Cart, Order**, and other supporting components.

The project was initially created by **Niranjan**, who established the base repository. The other team members forked the repository and contributed their implementations through their respective branches.
